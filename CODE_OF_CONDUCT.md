# Code of Conduct

## Our commitment

We want Vowena Site to be a welcoming, respectful place to contribute, whether you are fixing copy, shipping UI, or publishing technical content.

## Expected behavior

- Be kind, constructive, and specific.
- Give feedback that helps others improve the work.
- Respect the time and context of other contributors.
- Help new contributors understand project conventions.

## Unacceptable behavior

- Harassment, discrimination, or hate speech
- Personal attacks or intimidation
- Sharing private information without consent
- Repeated bad-faith disruption

## Scope

This applies in issues, pull requests, code review, discussions, and related project spaces.

## Reporting

If you need to report conduct concerns, contact maintainers privately through GitHub. If that is not possible, email `security@vowena.xyz` with the subject prefix `[conduct]`.

## Enforcement

Maintainers may remove content or restrict participation when needed to keep the project safe and productive.
