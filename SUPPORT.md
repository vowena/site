# Support

## Use issues for

- Reproducible site bugs
- Scoped content or UX improvements
- SEO, accessibility, or performance issues

## Before opening an issue

- Read [README.md](README.md) for setup and structure.
- Read [CONTRIBUTING.md](CONTRIBUTING.md) for the quality bar.
- Read [SECURITY.md](SECURITY.md) if the issue may be security-sensitive.

## Questions and routing

If discussions are enabled for this repository, use them for open-ended questions and early ideas. Otherwise, open an issue with enough context for maintainers to route it properly.
